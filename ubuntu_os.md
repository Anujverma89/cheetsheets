# Ubuntu 
* Ubuntu is unix based Opensource OS distribution of Linux OS. Linux is kernal and GNU as GUI layer making it as GNU LINUX ( complete OS ). 
* Kernel sits on top of hardware and we use Desktop environment like KDE or gnome to interact with kernel thus hardware.


# Shell 
* Shell is a medium through which we interact with CORE os for various tasks may be like searching something in system, running some app etc etc.
* Types of shell :
  * GUI shells : like windows explorer, GNOME.
  * CLI shells : like bash, zsh etc
 
# Ownership : 
* root : owns everything in a system.
* specific user : like desktop users.
* User - Group - other

# Permissions : 
* Read, write, execute

# directory : 
* /dir/

# files : 
* /file

# Note : 
* In unix based system when you run a program or executable as some user that executable has accesses to all the resources that are owned by user and has permission to access. So it is recommended to run a programe or any executable with specific user permission.
